# BlinkIT-Business-Insights

## Project Overview

This project focuses on analyzing BlinkIT grocery sales data using Python, SQL Server, and Power BI to uncover valuable business insights related to sales performance, outlet efficiency, product categories, and customer preferences.

The project follows a complete end-to-end Data Analytics workflow:

- Data Cleaning & Preprocessing using Python
- Data Storage & Analysis using SQL Server (SSMS)
- Interactive Dashboard Development using Power BI
- Business Insight Generation through Data Visualization

---

## Technologies Used

- Python
- Pandas
- NumPy
- SQL Server (SSMS)
- Power BI
- Git & GitHub

---

## Project Workflow

### 1. Data Cleaning & Preprocessing (Python)

Performed data cleaning and transformation on the raw BlinkIT sales dataset:

- Removed duplicate records
- Handled missing values
- Standardized categorical values
- Renamed columns for consistency
- Performed feature engineering
- Exported the cleaned dataset for SQL Server analysis

---

### 2. Data Analysis (SQL Server)

Imported the cleaned dataset into SQL Server and performed business-focused analysis using SQL queries.

Analysis performed:

- Total Sales Analysis
- Average Sales Analysis
- Product Category Performance
- Outlet Type Analysis
- Outlet Size Analysis
- Outlet Location Analysis
- Fat Content Analysis
- Rating Analysis
- Revenue Contribution Analysis
- Top Performing Categories & Outlets

### SQL Concepts Used

- Aggregate Functions
- GROUP BY
- ORDER BY
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- Ranking Functions

---

### 3. Dashboard Development (Power BI)

Connected Power BI directly to SQL Server and created an interactive dashboard featuring:

#### KPI Cards

- Total Sales
- Average Sales
- Number of Items
- Average Rating

#### Interactive Filters

- Outlet Location Type
- Outlet Size
- Item Type

#### Visualizations

- Sales by Item Type
- Sales by Outlet Type
- Sales by Outlet Location
- Sales by Outlet Size
- Fat Content Analysis
- Outlet Performance Summary
- Sales by Establishment Year

---

## Key Insights

- Tier 3 outlets generated the highest revenue contribution.
- Regular-fat products accounted for the majority of total sales.
- Supermarket Type 1 emerged as the highest-performing outlet category.
- Fruits & Vegetables were among the top-selling product categories.
- Medium-sized outlets contributed the largest share of overall revenue.
